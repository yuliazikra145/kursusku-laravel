# Draft Artikel Ilmiah - KursusKu

## 1. Judul Sementara
Pengembangan Sistem Pendaftaran Kursus Berbasis Laravel dengan Pencarian dan Pagination Server-Side.

## 2. Problem Statement
Ketika data kursus semakin banyak, daftar kursus yang panjang tanpa fitur pencarian dan pagination akan menyulitkan pengguna dalam menemukan kursus yang diinginkan.

## 3. Gap
Sistem sebelumnya hanya menampilkan seluruh data sekaligus tanpa fitur filter status atau pencarian kata kunci, sehingga pengguna harus menggulir halaman panjang.

## 4. Metode
Metode pengembangan dilakukan secara bertahap: identifikasi kebutuhan, perancangan model data (Course), implementasi Laravel (Controller, Blade), hingga pengujian fitur menggunakan skenario fungsional.

## 6. Hasil Awal
Fitur pencarian (search) dan filter status berhasil mempersempit hasil sesuai kata kunci. Fitur pagination berhasil membatasi tampilan maksimal 10 data per halaman.
